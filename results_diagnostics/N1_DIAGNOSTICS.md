# N1 diagnostics (donor-level ROC + quantitative collinearity)
> Generated by `diagnose_n1.py` from the six REAL GEO series matrices. Independent output directory `results_diagnostics/`; `results/` and `results_m2b/` are untouched.

## 1. Why
Second-round peer review finding N1: `results/07_roc.csv` scored single-gene ROC/AUC on **array-level** expression, whereas the manuscript claims a donor-level analysis. This script tests whether that changes any number, and quantifies the ancestry x disease confounding that was previously described only in words.

## 2. Reconciliation of the array-level reference
Same probe (donor-level unadjusted OLS, smallest nominal p, gene-annotated), same score, same RNG seed. Recomputed array-level AUC matched `07_roc.csv` exactly on **6** rows with **0** mismatches.

## 3. Donor-level result: the numerical finding is ZERO change
GSE2378-GPL8300 carries **one array per donor** (13 arrays / 13 donors; min = max = 1.0 arrays per donor). Collapsing technical replicates therefore changes nothing on this platform: donor-level AUC equals array-level AUC on all six genes (max |delta| = 0.000000), range **0.119–1.000**; donor-level permutation p **0.002–0.994**.
**Therefore N1 is a reporting/circularity problem, not a numerical error**: `results/07_roc.csv` needs no number changed. The real weakness is that the probe was chosen by smallest nominal p on the SAME 13 donors on which the AUC was then computed. Table S7 quantifies this: the median AUC across ALL probes mapped to a gene, and the AUC of a selection-free gene score (median expression across those probes), are both reported alongside the selected-probe AUC.
Across the six genes, selected-probe AUC minus the all-probe median AUC ranges **-0.119 to 0.190** (median 0.000): the choice of a single probe can shift apparent discrimination by up to 0.19 in either direction.
These AUCs are descriptive only: no independent cohort, no multiplicity adjustment in the original `07_roc.csv` permutation p (BH-adjusted values are supplied in Table S7), and wide bootstrap CIs (e.g. 0.571–1.000). They must not be read as evidence of diagnostic discrimination; the apparent contrast with the non-significant BH q values in M2 is a consequence of selection bias, not a discrepancy between models.

## 4. Collinearity: LINEAR diagnostics are mild, STRUCTURAL confounding is not
- **GSE9944-GPL571**: phi = -0.3536, r(glaucoma, Caucasian) = -0.3536, VIF(glaucoma) = 1.1429, condition number = 3.7581, smallest cell = 0.0, zero cell = YES (a zero cell).
- **GSE9944-GPL8300**: phi = -0.3721, r(glaucoma, Caucasian) = -0.3721, VIF(glaucoma) = 1.1607, condition number = 6.2863, smallest cell = 0.0, zero cell = YES (a zero cell).

On GSE9944-GPL571 every glaucoma donor is African American and every Caucasian donor is a control (a zero cell), so ancestry and disease are partly separated; the adjusted disease coefficient is not interpretable even though the design matrix is full rank. Note that VIF (1.14–1.16), |r| (0.35–0.37) and condition numbers (3.76–6.29) are all mild: the problem is **structural imbalance / a zero cell**, not classical multicollinearity. The manuscript wording should therefore say 'unbalanced ancestry–disease structure with a zero cell' rather than 'nearly collinear'.
